Projects/paneb-videogen

Android app + API · Kotlin · TypeScript

Short AI videos, from prompt to player.

An Android (Kotlin/Compose) app plus a Node/TypeScript API that turns prompts and images into short videos. Providers are swappable: a free mock for development, Kling in the cloud, or ComfyUI + LTX on your own GPU. The provider key never leaves your API — the app talks to it with a per-user key and signed video links.

What it does

Create on the phone, render where it makes sense.

  • Create, history, player

    The Android app creates jobs from prompts and images, follows the queue and plays the finished videos.

  • Swappable providers

    One API, three backends: mock (free, finishes in ~15 s), kling (prepaid cloud packages) and comfyui (LTX on your own NVIDIA GPU).

  • Queue, SQLite, worker

    Express API with a job queue, SQLite persistence via node:sqlite, background worker, video storage and an OpenAPI contract (backend/openapi.yaml).

  • Signed links, isolated users

    Per-user app keys, signed video URLs, seed-based repeat/variations and tested isolation between users.

  • Prompt enhancement

    Optional prompt enhancer before dispatch — see docs/prompt-enhancement.md for the details and limits.

  • Documented and tested

    Architecture, data model, API reference and provider guides under docs/; npm test covers model, security, migration, OpenAPI contract, metrics and clean shutdown.

Providers

Start free, pay or self-host when ready.

ProviderCostWhat you need
mock Free Nothing — the default for development.
kling Paid (prepaid packages) No hardware; legacy API implemented, new API on the roadmap.
comfyui (LTX) Electricity / GPU Powerful NVIDIA GPU (officially 32 GB+ VRAM); depends on your workflow.

Choosing guide: docs/providers/README.md. Adding a new backend: docs/adding-a-provider.md.

Quick start

Three minutes, nothing to spend.

cd backend
npm install
cp .env.example .env   # set APP_KEY; PROVIDER=mock is the default
npm run dev            # requires Node >= 22.13

Try it: curl -H "X-App-Key: <your key>" -F prompt="astronaut cat" localhost:3000/jobs and poll /jobs/<id>. Then open android/ in Android Studio.
