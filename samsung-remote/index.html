Projects/Samsung Remote

Desktop & Android app · Tauri 2 + Rust

Your Samsung TV, from your desktop and phone.

An unofficial Tauri 2 app that talks to Samsung (Tizen) TVs over your local network — pairing, real app lists, the Guide key and fast controls. SmartThings is the fallback for waking the TV from standby.

  • Tauri 2
  • Rust
  • TypeScript
  • Android
  • v0.1.0

What it does

Local first, cloud when the TV is asleep.

  • Direct local connection

    Talks to the TV over a secure WebSocket on port 8002. Pairing happens with a pop-up on the TV, and the token stays on your device.

  • Finds your TV

    SSDP discovery lists the TVs on the network with name and model; you can also type the IP manually.

  • Real app list

    Loads the apps installed on your model and lets you add them as shortcuts, with reorder and remove.

  • Full remote

    Power, volume, mute, D-pad, Guide, channels, inputs, playback, PVR, ambient mode and the numeric keypad.

  • Type and search

    Send text to the field in focus on the TV, or search directly from the app — no on-screen keyboard marathon.

  • SmartThings fallback

    Add a personal SmartThings token to wake the TV from standby and send cloud commands when the local connection is not available.

  • Android build

    The same Tauri 2 codebase compiles for Android. The README covers the SDK, NDK and APK signing steps.

  • Local by default

    Pairing and SmartThings tokens are stored on the device. Control traffic goes to the TV on your LAN; the cloud is only the fallback.

Quick start

Node 22+, Rust stable and the platform build tools.

npm install
npm run tauri dev

Build a desktop installer with npm run tauri build; the artifacts land in src-tauri/target/release/bundle. 

# Android (Tauri 2 mobile)
npm run tauri android init
npm run tauri android build -- --apk --target aarch64

The APK is unsigned by default; the README has the zipalign and apksigner steps for sideloading.

How it works

Two transports, one remote.

PathWhat it uses
Discovery SSDP M-SEARCH on 239.255.255.250:1900; name and model from http://<ip>:8000/api/v2/.
Local control wss://<ip>:8002/api/v2/channels/samsung.remote.control with KEY_* commands and a pairing token saved in local.json.
Apps and text ed.installedApp.get for the real app list; SendInputString + SendInputEnd for typing.
Cloud fallback SmartThings API for power from standby, volume, inputs, channels and modes; the token stays on the device.
