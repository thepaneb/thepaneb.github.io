Why use this template

Zero local setup, debugger ready.

  • Zero local setup

    Python and the dependencies live inside the container. Only Docker is required.

  • Python 3.15 + extensions

    Debian 13 (trixie) with Pylance, Ruff, Black, pylint, pytest and debugpy already installed.

  • Blueprint structure

    Routes live in app/modules/<name>/, ready to grow without refactoring.

  • uv everywhere

    pyproject.toml + uv.lock, with reproducible installs via uv sync --frozen.

  • Debug ready

    Press F5 and the app starts on port 40000 with breakpoints enabled.

  • Predictable time zone

    America/Sao_Paulo is set for reproducible dates in logs and reports.

Quick start

Four steps, no local Python install.

1. Click "Use this template" → "Create a new repository"
2. Clone your new repository and open the folder in VS Code
3. Accept "Reopen in Container" when prompted
4. Press F5 and open http://127.0.0.1:40000

Requirements: Docker running, VS Code and the Dev Containers extension. To use it without creating a repository: git clone https://github.com/thepaneb/base_flask.git. 

.
├── .devcontainer/devcontainer.json   # Python 3.15-trixie image, uv feature, port 40000
├── .vscode/
│   ├── extensions.json               # recommends the Dev Containers extension
│   └── launch.json                   # "Flask Debugger" (debugpy)
├── app/
│   ├── __init__.py                   # creates the Flask app, registers blueprints
│   └── modules/
│       ├── hello_world/__init__.py   # GET /, /hello-world, /hello_world
│       └── status/__init__.py        # GET /status (health-check)
├── dev/dependencies.sh               # uv sync --frozen (container postCreate)
├── pyproject.toml / uv.lock          # dependencies (Flask, requests, tzdata)
├── .python-version                   # 3.15.2
└── AGENTS.md                         # guide for coding agents

Endpoints

A small, working surface to build on.

Run and debug

ActionHow
Start with the debuggerF5 → Flask Debugger
URLhttp://127.0.0.1:40000
Reinstall dependenciesuv sync --group dev (or bash dev/dependencies.sh)
Run without VS Codeuv run flask --app app run --host 127.0.0.1 --port 40000
 
# Quick check without starting a server
uv run python -c "import app; c=app.app.test_client(); print(c.get('/').get_json()); print(c.get('/status').status_code)"

The launch profile uses --no-debugger --no-reload on purpose: Flask's own debugger and reloader conflict with debugpy breakpoints.
